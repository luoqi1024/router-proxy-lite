The `licenses/` directory preserves seven primary upstream license/notice texts: sing-box, the SagerNet rule generators, Mozilla MPL, Go runtime, yaml.v3, UPX, and domain-list-community. These add approximately 28 KiB to the runtime bundle. They are **not** a completed inventory of all transitive dependencies.

`tools/source-bundle.py` reads the raw manager/core binaries' Go build metadata, checks each dependency ZIP against its embedded Go `h1` checksum, and packages matching module sources/notices, the pinned original core source archive, tracked RouterLite code, and the registry modification script. The result is a **source candidate**: full offline rebuilding and final corresponding-source review remain required. Build scripts use `-buildvcs=false`; each core build extracts into a new directory to avoid stale source files.

Before publicly distributing binaries: resolve data terms, complete transitive notice review, validate the source candidate and hardware installation/recovery, and establish a trusted release channel. Source traceability and checksum validation alone do not certify redistribution rights. The local preview is not represented as a distribution-ready release.
