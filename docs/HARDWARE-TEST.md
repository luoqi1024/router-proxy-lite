## 故障处理

从可信 LAN 登录 SSH，按实际安装位置运行维护脚本。例如安装在 `/overlay/routerlite` 时：

```sh
sh /overlay/routerlite/scripts/manage.sh disable
RPL_DATA=/overlay/routerlite/state sh /overlay/routerlite/scripts/network.sh stop
```

安装在 `/data/routerlite` 时相应替换路径。检查 `RPL_MARK` / `RPL_DNS`、表 3180、优先级 10820 的归属，不要清空全局 iptables 或路由表。确认自有规则已清理后，再按其他代理自身的文档恢复其服务；安装器不负责其他代理的启动项。
