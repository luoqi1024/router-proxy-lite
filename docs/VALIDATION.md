## 通过的检查

- `go test ./...`：8 组测试，含解析/限制、私网下载地址拒绝、会话与跨站保护、订阅/设置流程、公开接口脱敏、保存/运行失败回退、损坏状态、拒绝实机使用公开演示口令。
- 同一测试设置 `RPL_TEST_CORE` 后，调用本机编译的真实内核 `check`：五种协议及 VMess WebSocket 示例、两种代理策略，共 12 份配置通过。只验证配置可接受，**没有实际连到代理节点**。
- `go vet ./...` 通过。
- 5 个 shell 服务/安装/维护文件经 WSL `sh -n` 通过。
- `python3 tests/test_network.py`：4 组假网络命令测试，覆盖启停/状态、部分失败清理、不覆盖外部路由表、清理失败后保留所有权并重试。没有执行真实 iptables/ip 网络修改。
- Playwright：登录、示例导入、搜索/切换节点、开启、直连/分流切换、无效链接错误提示；1440px 与 390px 布局无横向溢出。最新截图在 `output/playwright/`（不提交 Git）。
- 页面无 JavaScript 运行错误；未登录时的 401、故意提交无效链接时的 400 为预期响应。
