## 当前公开范围

维护者已选择审核后公开现有源码仓库，首个二进制目标限定为小米 AX1800 / MiWiFi 1.0.394 / ARMv7。源码公开与二进制 Release 分开验收；不能以源码可见替代新用户安装成功。

发布候选已完成隔离安装测试、固定数据转换和原始程序离线重建比较。公开安装包前还要在设备外保留可验证备份，完成当前候选的新安装、网页首次设密、实际联网、整机重启及回退。长时间运行和其他型号测试可作为后续工作，但 alpha 发布必须明确剩余限制。

2026-09-29：源码仓库已公开。候选对应源码基于 `e6c5158`，独立重建验证通过；ARMv7 运行包 9,484,087 bytes，安装预检需 11,444 KiB 可用持久空间。设备全新安装与重启验收仍是下一步。

实机安装阶段更新：`e6c5158` 候选两次离线全新安装成功，26 个文件校验、默认关闭、首次设置要求、自启动及损坏文件拒绝均通过。人工恢复完整旧版本后，程序和私有状态逐字节一致，HTTPS 恢复。当前停在手机网页首次设密确认阶段；新候选联网与整机重启仍未验收。
