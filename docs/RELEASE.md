# 发布与验证范围

## v0.1.0-alpha.1

首个公开版本以 **Alpha 预览版** 发布，仅提供 ARMv7 包。参考设备为小米 AX1800（RM1800）/ 原厂 MiWiFi 1.0.394。此版本允许试用，不代表通用兼容或稳定版认证。

已完成的发布基础：

- 当前文件和可达 Git 内容历史的已知私人信息检查；设备备份、订阅和凭据不进入发布文件。
- 固定 CA、DB-IP Lite 和 domain-list-community 的原始来源、许可、输入哈希与规则输出哈希。
- 运行包保留许可与 56 个已链接 Go 模块的上游声明，发布时同时提供完整对应源码、模块依赖和规则原始输入。
- 候选 `e6c5158` 的管理程序、内核、规则和许可汇编从独立源码包重建，原始及 UPX 二进制逐字节一致。
- 31 项隔离测试，以及 Go 测试、静态检查和 shell 语法检查。
- 候选包两次实机离线全新安装，26 个文件校验、默认关闭代理、首次设密要求、自启动登记与损坏文件拒绝。
- 人工恢复完整旧程序及私有状态，逐字节一致，旧代理 HTTPS 探测恢复。

发布标签仅更新版本标识和发布材料，不追加实机验收。公开下载附件附有 SHA256 清单，安装入口固定该版本每个文件的大小与哈希；没有独立签名，信任起点是 GitHub HTTPS 和发布账户。

尚未完成，必须随 Alpha 说明：

- 手机网页首次设密的完整人工验收，以及新版规则的实机端到端联网复测。
- 正式 HTTPS 下载入口到设备的完整安装流程；目前实机采用离线上传。
- 整机重启、断电启动、长时间负载、吞吐及峰值内存测量。
- 更多协议、自动切换全部故障场景、其他型号和架构。
- 正式卸载、断电后从设备外备份恢复，以及自动升级/自动回滚。

自启动登记成功不等于重启验收通过。人工回退也不等于产品已经支持自动升级。详细检查项见 [实机验证清单](HARDWARE-TEST.md)。

## 后续发布

1. 固定版本号和来源；在新的输出目录构建，不覆盖已发布资产。
2. 生成运行包及对应源码，复核全部许可和私密数据边界。
3. 按本次变更完成必要的软件与硬件验证，明确尚未验证的范围。
4. 使用 `tools/package-install.py` 生成固定版本的 HTTPS 安装入口、离线包和校验清单。
5. Release 同时上传完整对应源码及构建说明，不能仅依赖 GitHub 自动生成的项目源码 ZIP。
6. 确认下载可见性和资产完整性后更新使用说明。未经过验证的架构不发布安装包；完整验收前继续标记预览版。

相近项目包括 ShellCrash、clash-for-Miwifi 等。RouterLite 的目标是减少操作与功能，不宣称首次在原厂固件运行代理。
