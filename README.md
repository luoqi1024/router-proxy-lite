# RouterLite

在路由器上运行代理，用浏览器管理。

RouterLite 面向已解锁 SSH 的原厂固件路由器。安装后，导入订阅、选择节点并开启代理，连接到这台路由器主 Wi-Fi 或 LAN 的设备就能按所选策略上网，无需逐台安装代理客户端。

项目希望保留一个简单的使用流程：**装一次，之后在网页里操作。** 在已适配设备上，不需要更换原厂固件或扩大分区，原有的 Wi-Fi 和路由功能继续使用。

> 当前为开发预览，仅在小米 AX1800 原厂固件上完成部分实机验证，尚未发布正式安装包。其他型号、整机断电重启和长期稳定性仍待验证。

## 能做什么

- **导入订阅**：支持 Clash / Mihomo 格式的订阅链接，也可以直接粘贴配置内容，在路由器本地解析。
- **选择节点**：支持 AnyTLS、Shadowsocks（无插件）、Trojan、VLESS 和 VMess。不支持的节点或配置会在导入时提示。
- **故障自动切换**：选择当前节点和备用节点，共 2–5 个。当前节点连续连接失败后，自动尝试名单中的可用节点。
- **网页管理**：手机和电脑都能使用，提供代理开关、节点选择、密码修改和操作记录。

提供三种上网策略：

| 策略 | 工作方式 |
| --- | --- |
| 智能分流 | 匹配国内规则的连接和局域网连接直连，其余走代理 |
| 全局代理 | 互联网连接走代理，局域网连接直连 |
| 全部直连 | 所有连接直接上网，保留订阅和节点设置 |

分流结果取决于规则覆盖范围。切换节点或策略时，现有连接可能短暂中断。自动切换用于处理连接故障，不是带宽测速或负载均衡；详细行为见 [自动切换说明](docs/FAILOVER.md)。

## 哪些路由器可以安装

目前的实机验证设备是 **小米 AX1800（RM1800），原厂 MiWiFi 1.0.394**。测试保留了原厂固件和分区。

当前安装器面向 ARMv7 Linux，需要 root 权限，以及固件已有的 BusyBox、procd、iptables、TUN 和策略路由能力。LAN 与 WAN 必须独立，LAN 接口为 `br-lan`。**仅能登录 SSH，并不代表设备已经兼容。**

| 资源 | 当前要求 |
| --- | --- |
| 程序体积 | ARMv7 完整安装文件约 **8.84 MiB**，包含内核、证书、规则和许可文件 |
| 存储空间 | `/data` 或 `/overlay` 能容纳安装文件，并至少留出 2 MiB 余量 |
| 安装内存 | 至少 64 MiB **可用内存**；运行占用随连接数和负载变化 |

当前只接管 IPv4。检测到 LAN 全局或 ULA IPv6 地址时，会拒绝开启代理。ARM64、MIPS 和其他固件尚未完成适配验证。

更多设备要求与实测范围见 [兼容性说明](docs/COMPATIBILITY.md)。

## 怎么开始使用

**目前还没有公开的一键下载入口。** 开发者可按 [构建说明](docs/PROVENANCE.md) 生成开发包，在已适配设备上测试。

拿到完整开发包后：

1. 自行解锁路由器 SSH，确认原厂网络可以正常上网。
2. 将完整包上传到路由器，在包目录内依次执行环境检查和安装：

   ```sh
   sh scripts/setup.sh --check
   sh scripts/setup.sh
   ```

3. 安装完成后，终端会显示管理网址。手机或电脑连接这台路由器，打开该网址，首次设置至少 9 个字符的管理密码。
4. 在“节点”页导入订阅并选择节点，回到“概览”选择策略、开启代理。

安装后代理默认关闭，管理服务设置为开机启动。日常操作通过网页完成，电脑无需一直开机。这里设置的密码仅用于 RouterLite，与 Wi-Fi 和 SSH 密码相互独立。

上传方式、安装检查和故障处理见 [安装指南](docs/INSTALL.md)。

## 使用前了解这几点

- **覆盖范围**：只处理连接到这台路由器主 Wi-Fi 和 LAN 的设备。把它接到另一台路由器后，不会自动接管上级路由器下的其他设备。
- **管理方式**：网页仅绑定 LAN 地址，使用 HTTP，适合在可信局域网内管理。
- **订阅更新**：目前需要手动点击“更新”。订阅链接须能从路由器直连下载，无法下载时可粘贴配置内容。
- **维护能力**：暂不提供自动升级、设备级策略或网页配置备份。现阶段的验证范围和后续计划分别列在 [实机测试清单](docs/HARDWARE-TEST.md) 与 [后续重点](docs/ROADMAP.md)。

## 实现与开发

RouterLite 由 Go 编写的管理程序、原生 HTML/CSS/JavaScript 页面和精简的 **sing-box** 内核组成。管理程序负责订阅解析、配置和网络接管，代理协议由 sing-box 处理。路由器运行时无需 Node.js、Python、数据库或 Docker。

安装 Go 1.25 或更高版本后，可在仓库目录启动界面演示：

```sh
go run ./cmd/routerlite
```

打开 `http://127.0.0.1:8787`，首次设置管理密码后即可体验界面。演示模式可载入示例节点，不启动代理内核，也不修改电脑网络。
